# Halal Food Scanner — Public Downloads

This repository hosts the **public release APKs** for Halal Food Scanner.
The source code is maintained privately for security.

## Download the latest APK

👉 **[Download latest release](https://github.com/KHUYAB/Foods-Halal-Scanner-Releases/releases/latest/download/app-release.apk)**

Or browse all releases: https://github.com/KHUYAB/Foods-Halal-Scanner-Releases/releases

## Install instructions (Android)
1. Download `app-release.apk` to your phone.
2. Open the file; allow "Install from unknown sources" if prompted.
3. Install and open Halal Food Scanner.

## Note
- Only the compiled APK is shared here. Source code is not public.
- Auto-update (OTA) inside the app requires the app to be installed from a build that includes the configured update URL.
